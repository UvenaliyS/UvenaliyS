# 📱 Aztec Barcode Decoder

Python-скрипт для декодирования Aztec штрихкодов и других 2D/1D кодов из изображений.

## 🎯 Что это?

Aztec Code - это двумерный матричный штрихкод, который часто используется для:
- Электронных билетов (поезда, автобусы)
- Посадочных талонов
- Документов с цифровой подписью
- Идентификационных карт

## 🚀 Установка

### 1. Установите зависимости

```bash
pip install -r requirements.txt
```

### 2. Установите системные библиотеки (Linux)

Для работы `pyzbar` нужна библиотека `zbar`:

**Ubuntu/Debian:**
```bash
sudo apt-get install libzbar0
```

**Fedora/RHEL:**
```bash
sudo dnf install zbar
```

**macOS:**
```bash
brew install zbar
```

**Windows:**
Скачайте zbar DLL с [официального сайта](http://zbar.sourceforge.net/)

## 💻 Использование

### Базовое использование

```bash
python decode_aztec.py путь/к/изображению.png
```

### Примеры

```bash
# Декодировать изображение
python decode_aztec.py ticket.png

# Сохранить результат в файл
python decode_aztec.py ticket.png -o result.txt

# Подробный вывод
python decode_aztec.py ticket.png -v
```

## 📸 Подготовка изображения

Для лучших результатов:

1. **Сделайте скриншот** или сфотографируйте штрихкод
2. **Убедитесь** что код четкий и контрастный
3. **Обрежьте** изображение так, чтобы код занимал большую часть
4. **Сохраните** в форматах: PNG, JPG, JPEG, BMP, GIF

## 🔍 Поддерживаемые форматы

Скрипт использует `pyzbar` и поддерживает:

- ✅ **AZTEC** - Aztec Code
- ✅ **QR** - QR Code
- ✅ **DATAMATRIX** - Data Matrix
- ✅ **PDF417** - PDF417
- ✅ **EAN13/EAN8** - European Article Number
- ✅ **CODE128** - Code 128
- ✅ **CODE39** - Code 39
- И многие другие...

## 🐛 Устранение проблем

### "Штрихкоды не найдены"

1. Улучшите качество изображения
2. Увеличьте контрастность
3. Убедитесь что код не обрезан
4. Попробуйте другой угол/освещение

### "ModuleNotFoundError: No module named 'pyzbar'"

```bash
pip install pyzbar
```

### "Unable to find zbar shared library"

Установите системную библиотеку zbar (см. раздел Установка)

## 📝 Технические детали

### Deutschlandticket (пример с вашего скриншота)

Deutschlandticket использует Aztec Code для кодирования:
- ID билета
- Срок действия
- Класс (2. Klasse)
- Зона действия (deutschlandweit in der 2. Kl. im ÖPNV)
- Имя владельца

Формат данных обычно начинается с `#V1#` и содержит структурированную информацию в специальном формате UIC (Union Internationale des Chemins de fer).
